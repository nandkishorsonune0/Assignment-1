# OCI Card for Minors Landing Page

Modern, conversion-focused landing page built with Next.js App Router, Tailwind CSS, and Framer Motion.

## Tech Stack

- Next.js (App Router)
- TypeScript (strict mode)
- Tailwind CSS
- Framer Motion
- TanStack Query
- Zustand

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```
